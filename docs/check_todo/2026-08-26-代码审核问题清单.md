## AUD-20260826-001

### 前端允许“目的地完全没定”，但生成链要求具体目的地

| 属性         | 内容                                              |
| ------------ | ------------------------------------------------- |
| 优先级       | P0                                                |
| 状态         | 已关闭                                            |
| 首次确认     | 2026-08-26                                        |
| 解决日期     | 2026-08-26                                        |
| 当前产品决定 | 用户必须选择至少 1 个目的地；不提供目的地发现模式 |

原问题：问卷允许选择 `UNDECIDED` 并隐藏具体目的地，但请求仍从
`destinations[0]` 构造后端必填字段，形成“前端放行、契约拒绝”的断点。

解决方式：

- 前端状态只展示 `CONFIRMED`、`SHORTLISTED`；
- `PV2-01-003` 改为始终显示、始终必填、阻塞生成；
- 远端配置中的旧 `UNDECIDED` 由前端白名单过滤；
- 迁移 `0015_require_destination` 从当前发布配置克隆下一版并停用旧选项；
- v1 本地草稿定向清除旧状态，保留其他答案。

代码证据：

- [`descriptors.ts`](../../apps/web/src/lib/planner/descriptors.ts)
- [`planner-fields.ts`](../../packages/schemas/src/planner-fields.ts)
- [`persistence.ts`](../../apps/web/src/lib/planner/persistence.ts)
- [`0015_require_destination.sql`](../../infrastructure/migrations/0015_require_destination.sql)

验证：Web TypeScript 检查通过；目的地、配置、草稿、Schema 和迁移相关测试通过。
