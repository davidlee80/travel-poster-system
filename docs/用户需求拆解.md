# 旅行计划信息图系统——用户诉求清单

> 以下清单以 V1.6 设计为唯一依据，将技术设计还原为可追踪的用户需求。  
> 每项均附对应章节，便于后续建立 PRD、测试用例和验收矩阵。

## 十三、核心用户旅程汇总

### 旅程 A：匿名用户首次生成

```text
用户无账号进入系统
→ 系统自动创建匿名身份
→ 用户填写目的地、日期、人员、预算、节奏和约束
→ 系统同步校验输入
→ 返回生成任务
→ 用户查看进度
→ 先看到文字版计划
→ 再看到含图片的信息图页面
→ 用户按需导出 PNG/PDF
→ 计划在当前浏览器中保存 30 天
```

对应：UR-012～UR-056、UR-112～UR-150。

### 旅程 B：匿名用户注册并继承历史

```text
匿名用户已生成计划
→ 提交邮箱和密码注册
→ 原匿名身份原地升级
→ user_id 保持不变
→ 历史计划自动继承
→ 用户获得长期保存和跨设备访问能力
```

对应：UR-151～UR-154。

### 旅程 C：匿名用户登录已有账号

```text
用户在当前设备匿名生成计划
→ 登录已有注册账号
→ 匿名计划事务性归并到已有账号
→ 清除匿名身份
→ 用户在历史列表中看到原账号计划和匿名期计划
```

对应：UR-155～UR-161。

### 旅程 D：异常与降级

```text
模型或素材发生故障
→ 核心计划仍需通过 Schema 和业务规则
→ Hero 失败则使用城市图或渐变背景
→ 景点、美食图失败则使用占位图
→ 路线图失败则显示文字路线
→ PNG/PDF 单项失败不影响其他可用输出
→ 仅核心计划、模板或数据库发生阻断故障时任务失败
→ 用户获得明确错误码和重试指引
```

对应：UR-076～UR-080、UR-091～UR-111、UR-136～UR-143。
