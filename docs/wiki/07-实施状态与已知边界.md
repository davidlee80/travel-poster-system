## 当前生产默认与休眠能力

### 匿名模式

- 默认关闭，无会话访问不再现场建号；
- 匿名 token、配额、升级、归并、30 天清理和 `anon/` 内容空间仍保留；
- 测试同时覆盖关闭态和重新打开态；
- **归并与创建已解耦**（2026-09 修订）：`IdentityService.resolve` / `register` / `login` / `loginPhone` 的归并分支无论开关都执行，存量匿名数据不会被遗弃；
- **匿名身份不能生成**（2026-09 产品决策）：生成端点对 `userType === 'ANONYMOUS'` 一律 403 `AUTH_ANONYMOUS_FORBIDDEN`。这条拦截独立于匿名开关——即使重新打开匿名入口，匿名用户可以浏览和保留数据，但仍需注册后才能生成；
- 重新打开匿名入口仍需设置开关并按 [运维手册](../运维手册.md#重新打开匿名入口p7-的回切) 验证完整部署。

这意味着阅读 `users.user_type` 或匿名代码时不能得出“当前产品允许游客生成”的结论。

### fake 模式

仓库为无需付费凭据的开发环境提供 fake 实现，但它们只替换外部内容，不跳过主业务链：

| 能力       | fake 行为                   | 仍真实执行的部分                           |
| ---------- | --------------------------- | ------------------------------------------ |
| LLM        | 固定/请求驱动的杭州 fixture | 状态机、Schema、规则、修复、版本保存、编排 |
| Embedding  | 本地哈希词汇向量            | pgvector 查询、过滤、Top 5、隔离           |
| 图片生成   | 生成渐变/占位画面           | 配额、熔断、后处理、上传、metadata、绑定   |
| 授权图搜索 | fake 客户端                 | 超时/预算/合规入库/去重/复用路径           |

`fake` 全绿只证明接线与降级，不证明供应商端点、模型质量、真实图片内容或 SLA。

### CR 计费

- `CREDIT_BILLING_ENABLED=false` 是默认值；关闭时 credits 路由不注册，API/generation/render 三侧都不触碰钱包；
- 打开前必须应用到迁移 0013/0014，先给存量用户授予 CR，并确保三个进程同时打开；
- 0014 是“能跑通”的开发占位价，不是最终商业定价；真实价目、毛利和注册赠送额仍需产品决策；
- 当前没有支付网关/充值入口，`TOPUP` 只预留数据结构，运营通过 `pnpm user:credit` 授予；
- 默认换算 1 元=1000 CR，不能在已有余额后随意更改。

## 当前仍明确不支持或未完全实现

- 目的地未定/推荐（产品明确要求至少选择 1 个目的地，前端不提供“完全没定”入口）；
- 超过 5 个目的地；
- 超过 30 天的日期弹性，以及基于实时价格自动选日；
- 任意语言（仍仅 `zh-CN`）；币种仅 CNY/JPY/USD/EUR/GBP/HKD，且不在线换汇；
- 任意 HTML、外部 URL 或模型直接输出可执行展示；
- 用户上传图片；
- 在计划生成任务中自动导出所有文件（导出是用户主动的独立任务）。

多目的地与日期弹性已由 P9 取代 V1 的拒绝规则：N-10 现在校验 1～5 个目的地及布尔标记一致，N-09 上限为 30 天。阅读 V1.7 详细设计的“不支持范围”时必须结合 P9 实施计划。

## 推荐的近期技术顺序

1. 用 `probe:llm`/`probe:image` 验证真实端点，再开启一档用户 tier 灰度；
2. 接真实授权图源或灌入种子素材，随后做 Hero 预热；
3. 在完整 Docker 栈跑真实导出与 MinIO 生命周期验证；
4. 用真实流量验证 T1/T2 和命中率人工门禁；
5. 决定 CR 真实价目/赠送/充值，在存量用户授予后再三侧开启计费；
6. 补已归并 `anon/` 导出物的 90 天清理；
7. 按产品优先级补 VERIFY 数据源、跨设备草稿、行前文件后端、历史列表或重新生成入口。

## 判断“功能完成”的标准

对这个仓库，至少同时满足以下条件才能称为完成：

- 契约有 Zod 真相源，并被 API/Worker/Web 共用；
- 主路径和到底降级同时有测试；
- 数据归属、幂等、保留期与错误码已定义；
- 指标在 catalog 登记且实际注册，告警引用存在；
- Linux/Chromium/字体/原生依赖在 CI 或容器验证；
- 外部 Provider 功能已用真实凭据联调，不能只靠 fake；
- 人工 SLA/命中率目标以真实样本报告，不用本机假模型数据代替。
