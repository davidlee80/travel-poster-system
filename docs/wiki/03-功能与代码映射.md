## 修改功能时如何反查

以“新增一个 Planner 选项/条件码”为例，完整链路是：

```text
planner-fields.ts api_key + planner-profile.ts 枚举
  → descriptors.ts / config-binding.ts / planner_config_options
  → 通用控件
  → buildPlannerRequest planner_profile + conditions[]
  → packages/schemas conditions.ts 白名单
  → prepareRequest/describeConditions
  → Prompt 或 V-xx 规则读取
  → TravelPlan.constraint_report
  → 页面 ConditionSummary
  → 契约、Web、planning、门禁测试
```

只改 UI 标签不等于新增了业务能力；只改 Schema 又会让界面无法产生该值。类似联动清单见 [开发改动指南](08-开发改动指南.md)。
